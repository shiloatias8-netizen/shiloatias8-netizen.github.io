## חלק 2: העלאת האפליקציה

1. מחוברים ל-GitHub, לוחצים על **+** למעלה ובוחרים **New repository**.
2. ב-**Repository name** כותבים `milon` (באותיות קטנות באנגלית).
3. מסמנים **Public**. זה חובה כדי שהפרסום יהיה חינמי. אין באפליקציה שום מידע אישי.
4. לוחצים **Create repository**.
5. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
6. פותחים במחשב את התיקייה `אפלקציה קלוד לפועלים סרילנקים`, מסמנים **את כל מה שבתוכה** (Ctrl+A), כולל התיקיות `img` ו-`icons`, וגוררים לחלון של GitHub. עדיף לעשות את זה בדפדפן Chrome או Edge.

8. בודקים שברשימה מופיעים `index.html`, `words.json` והתיקיות `img` ו-`icons`, ולא תיקייה אחת שכל הקבצים בתוכה. אם כל הקבצים הגיעו לתוך תיקייה אחת, צריך למחוק ולהעלות שוב את **התוכן** של התיקייה, לא את התיקייה עצמה.

## חלק 5: הטלפון לא מקריא בעברית?

ההסבר הזה נמצא גם בתוך האפליקציה, בכפתור **?** למעלה.

**אנדרואיד:**
1. **הגדרות** ← מחפשים **"המרת טקסט לדיבור"** (Text-to-speech).
2. במנוע המועדף בוחרים **Speech Services by Google**. בסמסונג צריך לפעמים להחליף ממנוע של סמסונג.
3. לוחצים ⚙ ליד המנוע ← **התקנת נתוני קול** ← **עברית** ← מורידים. ההורדה חינמית ומאפשרת גם הקראה בלי אינטרנט.
4. אם האפשרות לא מופיעה, מעדכנים את "Speech Services by Google" ב-Google Play (חינם).

**אייפון:**
1. **הגדרות** ← **נגישות** ← **תוכן מוקרא** ← **קולות** ← **עברית** ← **כרמית** ← מורידים.
2. בודקים שמתג ההשתקה בצד הטלפון לא מופעל.

אחרי ההתקנה סוגרים את האפליקציה ופותחים אותה מחדש.

## איך מוסיפים או מתקנים מילים

כל המילים נמצאות בקובץ אחד: `words.json`.

1. ב-GitHub לוחצים על `words.json` ואז על העיפרון ✏ (Edit).
2. מעתיקים שורה קיימת ומשנים אותה. כל מילה נראית כך:

```json
{ "id": "patish", "category": "tools", "he": "פטיש", "say": "פַּטִּישׁ", "sound": "පටිෂ්", "si": "මිටිය", "en": "hammer", "image": "img/patish.svg", "checked": false },
```

| שדה | מה כותבים |
|---|---|
| `id` | שם קצר באנגלית, בלי רווחים, ושונה מכל מילה אחרת |
| `category` | אחד מאלה: `tools` (כלים), `materials` (חומרים), `actions` (פעולות), `safety` (בטיחות) |
| `he` | המילה בעברית, כמו שתוצג |
| `say` | מה הטלפון יקריא. אפשר לכתוב עם ניקוד כדי שההגייה תהיה נכונה. אם לא בטוחים, כותבים כמו ב-`he` |
| `sound` | איך אומרים את המילה העברית, באותיות סינהליות |
| `si` | התרגום לסינהלית |
| `image` | שם קובץ התמונה בתיקייה `img` |
| `checked` | משנים ל-`true` אחרי שפועל דובר סינהלית אישר שהתרגום נכון |

3. **הקפד על הפסיקים:** אחרי כל מילה יש פסיק, חוץ מהמילה האחרונה ברשימה. בלי זה האפליקציה לא תיטען.
4. לוחצים **Commit changes**.

**להחליף איור בתמונה אמיתית מהאתר:** מצלמים את הכלי, ב-GitHub נכנסים לתיקייה `img` ← **Add file** ← **Upload files** ומעלים, למשל `patish.jpg`. אחר כך ב-`words.json` משנים את `"image": "img/patish.svg"` ל-`"image": "img/patish.jpg"`. כדאי לבחור תמונה קטנה, עד כ-300KB (בוואטסאפ התמונות כבר מוקטנות).

**איך העדכון מגיע לטלפונים:** פותחים את האפליקציה עם אינטרנט, סוגרים ופותחים שוב. הפתיחה השנייה כבר מציגה את הגרסה החדשה.
